# Deploy (Cloudflare Pages)

Static Vite build — no server, no secrets.

| Setting | Value |
|---|---|
| Framework preset | Vite |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node version | 20+ |

Every push to `main` redeploys automatically once the repo is connected to a Pages project.
Local: `npm install && npm run dev`.
